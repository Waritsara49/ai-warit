รองรับการอัปโหลดไฟล์ข้อมูลจริง COVID-19 / โรคติดต่อทางระบาดวิทยา พร้อม Publish ผ่าน GitHub Pages

ขั้นตอนการนำ Dashboard ขึ้น GitHub Pages

ไฟล์ HTML นี้สมบูรณ์ในตัวเอง (Single File) สามารถฝากไฟล์บน GitHub Pages เพื่อแชร์แดชบอร์ดออนไลน์ให้ผู้บริหารและทีมงานดูได้ฟรีตลอดเวลา
  1. เซฟไฟล์นี้เป็น index.html บนเครื่องคอมพิวเตอร์ของคุณ
  2. สร้าง Repository ใหม่ในเว็บไซต์ GitHub.com (เช่น ชื่อ epi-dashboard)
  3. อัปโหลดไฟล์ index.html (รวมถึงไฟล์ confirmed-cases-since-280265.xlsx หากต้องการแนบเก็บไว้) ขึ้นไปยัง Repository
  4. ไปที่เมนู Settings → Pages ของ Repository
  5. ในหัวข้อ Build and deployment เลือก Source เป็น Deploy from a branch และเลือก Branch เป็น main หรือ master แล้วกด Save
  6. รอประมาณ 1-2 นาที GitHub จะสร้างลิงก์เว็บไซต์ Dashboard เช่น:
    https://your-username.github.io/epi-dashboard/
